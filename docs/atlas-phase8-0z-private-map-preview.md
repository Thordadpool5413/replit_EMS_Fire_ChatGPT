# Phase 8.0Z: private accepted address-point map preview

Adds a private server route that revalidates the active coordinate decision, current registry identity, acknowledged review and retained coordinate fields on every read and every map opening. A rollback, flagged or changed review, mismatched address, malformed history or modified coordinates blocks the map. Profile preview is limited to current independently county-verified, unshared candidates and authorized workspace sessions. The map link contains a decision ID and source key, not coordinates; server validates them before redirecting to Google Maps on explicit user navigation. No automatic third-party map requests. No national publication, route planner changes, or coverage increase. This is an address-point preview, not a station-location claim. Live Replit endpoint verification remains pending. Tests cover stale/rolled-back decisions and client response binding.
