# Phase 9.0T: recurring national federal address recovery

Run twice daily at 03:17 and 15:17 UTC; rotate through up to 96 unresolved NPPES source records per invocation using a deterministic 12-hour UTC slot, with manual offset support. The current 5,109 unresolved NPPES records are a queue, not unique facilities. Snapshot hashes, native NPI identity and parent record membership are checked. Query current NPPES v2.1 by exact NPI, with no state licensure dependency. Preserve source-reported primary/secondary/mailing evidence including cross-state addresses, and distinguish missing, ineligible, unavailable, changed name, missing primary, changed address and recovered address. Query at most 24 physical primary addresses per run via Census; exact source name and address match are required for review-only approximate points. No county/operating site verification, primary overwrite, automatic station identity or pin publication. Reports are retained as GitHub artifacts for 90 days; no database or frontend mutation, and the job does not claim all records refreshed if a scheduled run is missed. The queue offset wraps based on the current snapshot; a future phase can integrate successful evidence and persist checkpoints. Merge without waiting for CI per user direction.
