---
name: Verified-only directory
description: Product rule for separating source listings from verified operational profiles.
---

The default operational directory shows only fully source-verified profiles. Official source listings remain a separate reference view until their identity and every score-driving operational field have field-level evidence. Missing operational fields and scores remain unavailable rather than inferred.

**Why:** The user selected a verified-only default because the information presented to end users must be accurate.

**How to apply:** Do not promote an EMS license or fire registry row into a verified operating profile, merge records based only on similar names, or derive operational capability and score values from registry presence.
