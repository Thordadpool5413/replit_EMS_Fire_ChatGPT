# Phase 8.0T: authenticated GIS review acknowledgment

Server checks new GIS reviews against the 72 currently bundled review-only candidate signatures, exact account native identity, state, name and reported county. Existing protected entries are immutable and retained on full record replacement. Actor and acknowledgment time are assigned from the authorized Replit editor session; self-entered reviewer name is not authentication. No historical entry is retroactively authenticated. Applies to PUT, queued mutation and batch creation. Public profiles continue withholding review history. The catalog is derived from the bundled VA and multi-state evidence files in this commit and must be refreshed together with future candidate releases. No coordinates are promoted, no map overlay is changed, and no new database schema is needed. Tests include disposable authenticated API integration. Live deployment and client display of acknowledgment remain pending.
