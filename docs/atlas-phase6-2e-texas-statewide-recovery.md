# Phase 6.2E — statewide Texas batched recovery

The previous two local integrations completed with zero new qualifying points (Prosper 19 targets, Cumberland 28). This phase expands to the Texas Geographic Information Office official statewide StratMap address-point service: https://feature.geographic.texas.gov/arcgis/rest/services/Address_Points/stratmap_address_points_48_most_recent/MapServer/0. State program: https://geographic.texas.gov/stratmap/address-points.html. The published layer schema provides street, postal community/ZIP, county name and FIPS, source and record dates, but does not expose placement type. Label every resulting match "Placement not reported"; it does not establish rooftop, entrance, or a confirmed operational station. End-user confirmation remains required.

Use deduplicated, bounded batches of up to 16 already known provider addresses, max 120 requests. The whole state is in scope; 1,359 unmatched Texas records and 1,271 distinct address targets at baseline. Strict metadata service ID, exact normalized street/city/ZIP, county and FIPS reconciliation, source attribution presence, WGS84 coordinates, and no subaddress or ambiguous point. Incomplete results and unavailable batches are not guessed. A candidate release must pass the existing additive comparison gate and be reviewed against current main. This is a statewide targeted batch API ingestion, not a complete county archive download. The DataHub county archive ingestion remains a separate follow-up. No production changes, no external backend, no fabricated records.
