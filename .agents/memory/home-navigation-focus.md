---
name: Home and navigation focus
description: Product constraint for the territory map home screen and compact sidebar navigation.
---

Home displays only the Interactive U.S. Territory Map; do not add dashboard side panels or summary cards to the home screen. Keep workspace navigation groups collapsed by default, expand the active group, and retain all specialist tools rather than deleting them during navigation cleanup. The user also wants the app to be easier for end users and is open to removing features that are not necessary; reduce duplication and organize tools before deleting capabilities.

**Why:** The user explicitly asked for a map-only home screen, wants a more end-user-friendly app, and accepted a compact, reorganized sidebar without removing agency data or specialist tools.

**How to apply:** When changing Home or primary navigation, preserve the map-only landing view, remove duplicate entry points, and make secondary tools available through collapsed groups before considering any feature deletion.
