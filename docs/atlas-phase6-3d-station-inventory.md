# Phase 6.3D: optional station inventory and lifecycle evidence

Extends existing private Replit PostgreSQL observation JSON with optional integer quantities, explicit quantity scope, acquisition date, warranty end and service agreement end. No database migration or new storage provider is required for these optional JSON fields. Legacy rows and idempotent retries remain valid. Quantity requires a model and positive bounded integer; documented station totals require a public-document source. Software has no device quantity. Exact dates must be valid calendar days; acquisition cannot be later than observation; known end dates cannot precede known acquisition. The fields remain user-entered dated claims subject to independent review, not verified current inventory. No auto-sum across observations, no serial-number collection, no replacement forecast, no map or score changes, no grant attribution. Existing reviewed station map still exposes only the minimal manufacturer/date fields. Tests exercise validation, persistence and retry conflicts in disposable CI PostgreSQL. Production deployment and CI are outstanding. EMS-only stations without durable NERIS identities and full departmental inventory remain out of scope.
