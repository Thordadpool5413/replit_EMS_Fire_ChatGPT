# ATLAS production reconciliation

The Replit backend is the canonical root source for shared agency records and reviewed public-source evidence. Bundled registry listings remain source snapshots; they are not treated as user-owned agency records or proof of installed equipment.

No production records were accessed or changed during the Replit cutover. A production audit is not implemented in this workspace. If an audit is later authorized, use a separately approved read-only database principal, a bounded explicit scope, and a report that excludes private notes, contacts, drafts, and credentials.

## Research queue

Reports includes a saved-work-first research queue for monitors, CPR, ventilation, ePCR, billing, contract vendors, and expirations. Identity, category mapping, installed value, exact-value source, and local user review remain distinct. Only source-reported facts with matching agency identity, category, exact normalized value, valid source link, and valid entry timestamp receive a value-matched-source label. That label does not confirm current equipment.

Invalid dates, flagged facts, missing values, and unsubstantiated records are prioritized. No automatic device inference or revenue prediction is used. The competitive map remains a recorded-data view; it does not certify national market share, complete source coverage, or current equipment.
