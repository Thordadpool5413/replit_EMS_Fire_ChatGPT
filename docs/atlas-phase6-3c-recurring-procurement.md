# Phase 6.3C: recurring procurement collection, first expansion

Adds all six Chicago equipment-topic scopes and NYC EMS software to the existing daily, opt-in GitHub collection job, expanding from 8 to 15 bounded source scopes (up to 400 source rows before deduplication). Existing Replit API serves the validated public-only feed. No new storage provider, no private data, no automated provider attribution, no open-bid or replacement inference. Chicago native identity is purchase order plus revision; approval date and reported row amount are distinct from expenditure, remaining funds and actual expiration. Negative revisions are preserved; rows without a department or with descriptions exceeding the public feed limit are withheld. Version 1 feeds are accepted only with the exact legacy scope set, normalized without changing retained history, and new scopes begin without a baseline. Version 2 publishes the expanded scope set. Existing 400-record/90-day retention cap and explicit 48-hour staleness warning remain. Source errors stay unavailable and prior observations retain their original timestamps until ordinary retention eviction.

The daily schedule is still gated by ATLAS_PUBLIC_DISCOVERY_ENABLED; activation and successful live retrieval are not implied by this commit. Stage/state portal links remain navigation only; no new statewide or county data adapter is claimed. CI regression fixtures are not production records. No Replit deployment or production schema changes in this release.
