---
name: Home and navigation focus
description: Product constraint for the territory map home screen and compact sidebar navigation.
---

Home displays only the Interactive U.S. Territory Map; keep it full-width and do not add dashboard side panels, summary cards, or a selected-state inspector beside the map. Keep the contiguous U.S. visually centered in a polished cartographic backdrop, with Alaska and Hawaii insets visible and map colors unobscured. Preserve the metric selector, legend, zoom controls, distinct selected-state outline, and map click-through. Use map hover/accessibility labels and the existing territory views for state details. Use one sidebar entry per workspace and consistent in-page view tabs across desktop and mobile. In primary navigation, show a near-full-width standalone logo without the adjacent “EMS & Fire Territory Intelligence” wordmark; successive increases were still too small. Keep specialist research tools available, but place low-frequency data-health and backup controls in a separate Data & system area. Keep the geographic directory, agency-location map, and fleet/response map as views within one Territory workspace, preserving state, county, and city context as users switch views. Group Routes & notes and the Field dashboard under one Field Work entry, retaining both views and their route/saved counts. Keep account intelligence on the Field dashboard and route editing/visit notes in Routes & notes instead of repeating those actions on each dashboard card. Quick-start actions must never select the first agency implicitly; make agency selection explicit before opening its profile or creating a quote. The user also wants the app to be easier for end users and is open to removing features that are not necessary; reduce duplication and organize tools before deleting capabilities.

**Why:** The user explicitly asked for a map-only home screen and a more end-user-friendly app, then said the selected-state side panel adds no value and asked to give that space to the map. They also approved consolidating navigation, removing duplicate route/note actions, separating system controls, preventing arbitrary agency selection, and preserving area context when returning from a profile.

**How to apply:** When changing Home or primary navigation, preserve the full-width map-only landing view without a selected-state side panel, keep one entry point and matching view tabs across screen sizes, retain unique workspace capabilities, remove repeated actions, group system administration separately, and require explicit agency selection for account-specific actions. Keep the contiguous U.S. centered relative to the map canvas and retain visible AK/HI insets; any visual map translation must also be reflected in selected-state zoom/focus calculations. When users move from a map or directory to an agency profile and back, keep the selected state/county/city/category and map metric, region, and zoom; show the active area and an explicit return action.

**Logo constraint:** Keep the logo asset, size, position, crop, and styling unchanged while adjusting toolbar or navigation controls.

**Why:** The user has reiterated that toolbar-button sizing must not alter the logo.

**How to apply:** Scope CSS updates to control selectors; do not change logo assets or logo-related styles.
