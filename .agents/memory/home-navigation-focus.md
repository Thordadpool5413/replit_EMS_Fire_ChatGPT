---
name: Home and navigation focus
description: Product constraint for the territory map home screen and compact sidebar navigation.
---

Home displays only the Interactive U.S. Territory Map; do not add dashboard side panels or summary cards to the home screen. Use one sidebar entry per workspace and consistent in-page view tabs across desktop and mobile. Keep specialist tools available rather than deleting them during navigation cleanup. Keep the geographic directory, agency-location map, and fleet/response map as views within one Territory workspace, preserving state, county, and city context as users switch views. Group Routes & notes and the Field dashboard under one Field Work entry, retaining both views and their route/saved counts. Keep account intelligence on the Field dashboard and route editing/visit notes in Routes & notes instead of repeating those actions on each dashboard card. The user also wants the app to be easier for end users and is open to removing features that are not necessary; reduce duplication and organize tools before deleting capabilities.

**Why:** The user explicitly asked for a map-only home screen and a more end-user-friendly app, then approved consolidating navigation and removing duplicate route and note actions while retaining both Field Work views.

**How to apply:** When changing Home or primary navigation, preserve the map-only landing view, keep one entry point and matching view tabs across screen sizes, retain unique workspace capabilities, remove repeated actions, and keep specialist tools available until their value is established.
