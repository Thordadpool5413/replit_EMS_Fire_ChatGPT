# Phase 10.0: operational national station discovery

Make the retained NERIS source useful beyond profiles: index all 65,970 native station rows, including 65,967 source coordinates, by the actual reported station address state. Derive optional point county using the existing bundled generalized county polygons and official county IDs. Missing, ambiguous or outside-state geometry is explicitly labeled, never assigned a guessed county. Native station and parent IDs, source coordinates, names, address, dates and shared-point flags are preserved. State-level search (Fire/All) is enabled by default; county, city and text filters use the station's own reported geography, not parent state. Use 50 coordinate groups/page, keep the total 150 public-marker ceiling with existing primary/secondary layers, and group shared coordinates without merging identities. Visible station details open government source, map, full parent directory and uniquely linked saved accounts. No state licensure lookup or automatic account creation, no new primary pins, no claim that a coordinate is a verified operating station. Near Me mode is unchanged and does not yet include this layer. County boundaries are generalized, not survey or jurisdiction verification. Replit untouched.
