# Phase 8.0J: Virginia address acquisition
Official VGIN statewide layer on Virginia DCR: https://dsfmportal.dcr.virginia.gov/server/rest/services/CivilReference/Civil_Reference_Layers/MapServer/1 . Pinned item, schema, bounded address-number and ZIP queries, strict street/postal city/state/ZIP and independent Census county checks, WGS84 bounds, source-native object IDs, source metadata and snapshot digest. Lifecycle and placement domains have not been verified; their literal values remain review-only, and every candidate requires end-user validation. No publication, coordinate changes, operational station claims, identity merges or Replit deployment. Source unavailability and ambiguous records are not counted as matches. CI fixture is synthetic test data only, not shipped provider records.
