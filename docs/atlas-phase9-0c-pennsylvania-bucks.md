# Phase 9.0C: Pennsylvania county recovery pilot

Pennsylvania has 746 actionable source records nationally ranked second. PASDA publishes Bucks County Site Address Points, March 2025 edition (https://www.pasda.psu.edu/uci/DataSummary.aspx?dataset=2081; https://mapservices.pasda.psu.edu/server/rest/services/pasda/BucksCounty/MapServer/14). Query only records reporting county 42017. Check actual published layer schema, exact address, postal community, ZIP, county label, lifecycle, source identifier and bounds. County is not independently verified, and source edition is historical; no automatic acceptance or station claim. Blair County's public layer lacks postal city and ZIP, so it is not eligible for this exact-address contract. The statewide 911 dataset is not assumed accessible. Results remain review-only; no registry writes. Live CI required.
