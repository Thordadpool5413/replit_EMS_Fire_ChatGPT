# Phase 9.0T: nationwide federal secondary practice-location acquisition

CMS publishes a Practice Location Reference File containing non-primary locations for Type 1 and Type 2 NPIs in the monthly downloadable archive: https://download.cms.gov/nppes/NPI_Files.html. Use the exact November 9, 2026 V2 release and SHA-256 already recorded by the current primary national location build. The national snapshot is checked for all 19,567 supported NPPES parents and the monthly release match; this is not a state licensing check. Stream the secondary CSV only, allowlist organization address columns, join by native NPI, exclude historical parents and unsupported/non-US rows, preserve line 2 and literal postal code, retain cross-state addresses, deduplicate full addresses per NPI and identify shared addresses across NPIs. Distinguish source row from station identity; never replace the primary address, create new provider accounts, assign counties, or publish pins from this file. Results are deterministic, source-hashed, partitioned by NPI prefix, and delivered as a CI artifact for profile integration. No phone/fax/contact data retained. Coverage metrics remain separate from national primary mapped records. The full monthly archive is large; live acquisition can fail independently of code merge. Update source pin with the primary snapshot when the next edition is acquired. No Replit changes.
