# Download Departments

Here you can download a comma-separated text file of United States fire departments listed in the National Fire Department Registry.

What information is included in the files?

These files contain the following information in a comma-separated value (CSV) file format:

- Department ID
- Department name
- Headquarters address
- Mailing address
- Telephone number
- Fax number
- County
- Website address
- Department type
- Organization type
- Number of stations
- Number of active firefighters
- Number of nonfirefighting personnel
- Department’s status as primary emergency management department

**Important information about Fire Department Identification Numbers (FDIDs)**

Please note that each state assigns FDIDs — not the U.S. Fire Administration — so it is possible for the same FDID number to exist in two or more states.
