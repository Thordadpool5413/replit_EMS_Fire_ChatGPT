---
name: Home and navigation focus
description: Product constraint for the territory map home screen and compact sidebar navigation.
---

Home displays only the Interactive U.S. Territory Map; do not add dashboard side panels or summary cards to the home screen. Use one sidebar entry per workspace and consistent in-page view tabs across desktop and mobile. In primary navigation, show a near-full-width standalone logo without the adjacent “EMS & Fire Territory Intelligence” wordmark; successive increases were still too small. Keep specialist research tools available, but place low-frequency data-health and backup controls in a separate Data & system area. Keep the geographic directory, agency-location map, and fleet/response map as views within one Territory workspace, preserving state, county, and city context as users switch views. Group Routes & notes and the Field dashboard under one Field Work entry, retaining both views and their route/saved counts. Keep account intelligence on the Field dashboard and route editing/visit notes in Routes & notes instead of repeating those actions on each dashboard card. Quick-start actions must never select the first agency implicitly; make agency selection explicit before opening its profile or creating a quote. The user also wants the app to be easier for end users and is open to removing features that are not necessary; reduce duplication and organize tools before deleting capabilities.

**Why:** The user explicitly asked for a map-only home screen and a more end-user-friendly app, then approved consolidating navigation, removing duplicate route/note actions, separating system controls, preventing arbitrary agency selection, and preserving area context when returning from a profile.

**How to apply:** When changing Home or primary navigation, preserve the map-only landing view, keep one entry point and matching view tabs across screen sizes, retain unique workspace capabilities, remove repeated actions, group system administration separately, and require explicit agency selection for account-specific actions. When users move from a map or directory to an agency profile and back, keep the selected state/county/city/category and map metric, region, and zoom; show the active area and an explicit return action.
