---
name: Home and navigation focus
description: Product constraint for the territory map home screen and compact sidebar navigation.
---

Home displays only the Interactive U.S. Territory Map; do not add dashboard side panels or summary cards to the home screen. Keep workspace navigation groups collapsed by default and retain specialist tools rather than deleting them during navigation cleanup. Keep the geographic directory, agency-location map, and fleet/response map as views within one Territory workspace, preserving state, county, and city context as users switch views. Group Routes & notes and the Field dashboard under one Field Work entry, retaining both views and their route/saved counts. The user also wants the app to be easier for end users and is open to removing features that are not necessary; reduce duplication and organize tools before deleting capabilities.

**Why:** The user explicitly asked for a map-only home screen, wants a more end-user-friendly app, and asked to consolidate Territory and Field Work views without losing their distinct capabilities or context.

**How to apply:** When changing Home or primary navigation, preserve the map-only landing view, keep one entry point with clear view tabs for Territory and Field Work, remove duplicate entry points, and keep specialist tools available rather than deleting them before their value is established.
