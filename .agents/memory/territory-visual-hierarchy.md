---
name: Territory visual hierarchy
description: User-stated visual direction for territory and county exploration screens.
---

For territory exploration, make the map and selected-area summary the visual focus. Use clear contrast, readable metric sizing, and deliberate card hierarchy. Keep lower-level geography and source metadata available through expandable details rather than letting it compete with the main task.

**Why:** The user repeatedly said the territory and county screens did not feel visually impressive or professional.

**How to apply:** Use this hierarchy across the Territory workspace while preserving all available data, citations, and actions.
