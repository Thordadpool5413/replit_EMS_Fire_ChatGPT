# Phase 9.0B: recovery checkpoints

National queue verified 13,831 actionable raw source records and 12,818 distinct address targets. Texas has 1,126 remaining records; its previous successful StratMap run reported 1,114 no-matches and no last-edit marker, so these cannot be treated as source-version-bound negative checkpoints. North Carolina has 460 actionable records and is the next checkpoint pilot. A checkpoint defers only an identical recent (at most 7 days) no-match result for the same source and metadata fingerprint with an observed last-edit marker, after an unchanged final metadata check. Changed snapshot/record/source, ambiguity, failure, unattempted or positive results never defer. No automatic historical backfill or reuse of coordinates. Output is a review-only artifact; existing public release logic remains unchanged when checkpoint is absent. A prior artifact must be explicitly supplied to the CLI; recurring retrieval and durable retention are not enabled yet. Live acquisition is read-only. No Replit modifications.
