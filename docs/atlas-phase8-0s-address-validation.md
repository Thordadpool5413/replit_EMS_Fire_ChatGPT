# Phase 8.0S: persistent address candidate review

Adds a dedicated GIS address evidence review field, separate from identity.address, using existing append-only local history and FACT_REVIEW outbox. Source binding includes native identity, snapshot generation, government object, update date, placement and county/shared-point status. Confirmation requires an independently checked basis and remains address evidence only. Changed evidence needs renewed review. Corrections are disallowed on this field, and confirmation does not create an accepted map pin, change original registry data, merge identities or verify operational stations. Existing synchronization queue is reused; no Replit deployment or database migration. Cloud acknowledgment in a deployed workspace is not verified. Tests cover persistence, exact source binding, flagged evidence and forbidden correction. Full CI required.
