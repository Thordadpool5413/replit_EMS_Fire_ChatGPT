# Phase 9.0S: nationwide NPPES practice-location evidence
The official NPPES v2.1 API returns a primary LOCATION address and separate practiceLocations collection. The official NPI files describe the non-primary practice location reference file: https://download.cms.gov/nppes/NPI_Files.html. Use exact organization NPI without a state or state licensing filter, bounded JSON, active Type 2 ambulance taxonomy, source date, allowlisted US address fields, distinct mailing / primary / secondary roles and full address deduplication (including suites). A missing secondary collection is distinct from an empty collection. Different-state evidence is preserved and labeled rather than rejected. Conflicting primary records, duplicate rows, malformed/foreign addresses and mailing rows are not treated as operating stations. No phone, personal contacts or unrelated data retained. End-user validation, original NPI source link and no automatic identity assignment. The individual profile can retrieve federal addresses and optionally request a Census approximate street-range location for a reported physical practice address only; does not publish a map pin, alter the saved provider or generate station IDs. National source coverage unchanged. CI smoke uses an observed public ambulance NPI; merge per user direction without waiting.
