# Phase 6.6A — Application functionality audit, first stabilization pass

Static inspection of the selected-account command center, evidence client, field plan, coaching, workspace mutation, pipeline, leadership and analytics services, and main CI workflow found two coverage gaps: UI selection did not require full source-native identity readiness and sample display relied on a scheduled expiry rather than checking freshness synchronously; the existing PWA worker tests were not part of primary CI. This change adds shared command-selection and sample eligibility, binds sample to state and source identity details, withholds stale/offline samples on render and rechecks on visibility/focus. No new feature or production data writes. Adds cross-service regression coverage for reviewed solicitation -> visit draft -> explicit coaching task -> journal replay -> completion -> leadership/analytics, ensuring no recorded contact, stage or unrelated account change. Existing PWA unit suite now runs in CI. Full browser/production deployment audit is not complete; authenticated UI navigation, real Replit sync, mapping coverage, performance, authorization, shared pipeline, and release acceptance remain distinct gates. Test fixtures only. User controls Replit deployment.
