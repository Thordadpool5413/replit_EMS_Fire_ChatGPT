# Phase 8.0U: server acknowledgment and coordinate publication gate

Adds a fresh private agency API read for GIS evidence status. Cached or client-supplied stamps are not evidence; server response must contain the matching current candidate, decision, actor and timestamp. Newer unsynced or conflicting reviews withhold acknowledgment. Public/redacted, missing or failed responses do not confirm anything. Displays status and explicit reasons why no candidate is published. No coordinate publication is enabled in this phase: independent coordinate provenance, placement, county, conflict resolution and an explicit authorized publish/rollback workflow remain required. No national snapshot or map change; no Replit deployment. Regression tests cover server/local distinctions, changed source, conflicting decisions and fail-closed publication.
