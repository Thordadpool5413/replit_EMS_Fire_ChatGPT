# Phase 6.2B — New Jersey statewide location recovery

Baseline: 46,791 supported public source identities; 30,137 mapped, 14,073 no-match. NJ has 1,440 records, 1,137 mapped, 271 unmatched, 31 not eligible and one historical. These are source identities, not a count of unique active facilities.

Official New Jersey Office of GIS NG911 service: https://services2.arcgis.com/XVOqAjTOJ5P6ngMu/arcgis/rest/services/AddressPoints/FeatureServer/0. Use bounded queries for already recorded organization street numbers and postal codes only. Require active primary address subtype, US/NJ, complete exact normalized street, postal community and ZIP, no subaddress, supported rooftop or parcel-centroid placement, valid dates and state bounds. Decode the service's published 21-county coded domain into Census county identities; do not assume codes are FIPS. Reject unknown/conflicting county, ambiguous or unsupported point, incomplete source results and changed metadata. Retain original provider identity/address, point record ID, authority, placement and real record update date (if supplied); do not equate parcel centroids with an operating station. End-user validation remains required.

The isolated atlas/regional-address-recovery-v2 workflow targets NJ only, with a bounded request budget and separate review-only candidate branch. It does not write to Replit production or change provider records. No additional mapping count is claimed before the workflow completes and candidate is independently checked. Replit remains the application backend; GitHub is source control and CI.
