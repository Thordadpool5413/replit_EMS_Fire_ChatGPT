# Phase 6.5C — Selected territory performance analytics

Read-only analytics for the same up-to-eight eligible selected accounts within a fresh five-minute reviewed sample. Equal inclusive 30/60/90-day current and prior contact windows using recorded local dates, task cohort current status (not historical or on-time completion), coaching-tagged standalone task subset, actual changes between adjacent retained working-stage records (UTC timestamps; no conversion rate), current document/location/competitive/device coverage denominators and account breakdown. Unavailable records and zero denominators remain explicit. No inferred rep performance, revenue, market penetration or causation, automatic tasks or new backend. Working pipeline is browser-local, not a shared CRM. Historical trends for evidence coverage and task completion require timestamped history not currently available. End-user validation required; test fixtures only. Replit deployment user-controlled.
