# Phase 6.2J - station competitive intelligence (first release)

Adds private dated equipment observations for saved departments with an exact NERIS station relationship. Replit API and PostgreSQL are the only persistence layer. Categories include monitor/defibrillator, mechanical CPR, ventilator, and software. Manufacturer, optional model/apparatus reference, actual observation date, evidence basis and description are explicit user inputs; no prefilled equipment facts. Public-document submissions require an HTTPS link, which is not automatically fetched or verified.

The existing private editor/viewer allowlist protects all routes. Each submission is immutable and idempotent; a different authorized editor must explicitly attest to their independent review and supply a rationale. A single terminal acceptance/rejection is recorded. Acceptance means a dated observation was reviewed, not proof of current ownership, complete inventory, manufacturer exclusivity, or a location verified in the field. No propagation to parent department fleet, national map or opportunity scores. Profile-level filters apply to the latest 100 observations only and separate pending, rejected, reviewed ZOLL, reviewed other named manufacturers and unclassified evidence. No automatic replacement prediction; no national map coloring until a coverage-aware review aggregation is implemented. EMS-only and USFA records without durable station IDs remain excluded.

Production rollout requires a database backup, review and non-destructive application of the additive facility_equipment_observations table and index in Replit, authorization configuration and live multi-user validation. CI uses disposable PostgreSQL only. No live deployment or production data changes. Historical observations are not rewritten; correction/supersession workflow remains future work.
