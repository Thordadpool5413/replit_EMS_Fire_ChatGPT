# Phase 6.6G — Client/API integration stabilization

Adds a disposable PostgreSQL integration test that mounts the real API app and executes the actual frontend shared-pipeline client over HTTP using independent cookie-authenticated sessions. Tests explicit qualification, permissions, stale revision rejection, cross-session reads, stage history, CRM separation, leadership and analytics counts, offline/expiry withholding, origin rejection and revoked-session rejection. Client validates returned record binding, edit permission and revision before reporting success; malformed responses fail closed. Unit tests exercise malformed/foreign responses and the private no-store transport. Existing responsive browser/map/profile and service-worker checks remain in CI. The integration transport simulates browser cookies, not a real desktop/mobile browser session or OIDC login. No live deployment, production database, external AI call or source mapping edits. Synthetic test fixtures are confined to disposable CI. Full real-device, Replit OIDC, schema migration and live cross-device acceptance remain required.
