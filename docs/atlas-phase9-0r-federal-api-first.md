# Phase 9.0R: federal API-first ambulance evidence

CMS Data API 2024 provider-and-service version 335e5f35-eca6-482d-87b3-f99883e213e3 (published May 21, 2026). Source: https://data.cms.gov/provider-summary-by-type-of-service/medicare-physician-other-practitioners/medicare-physician-other-practitioners-by-provider-and-service . Data dictionary: https://data.cms.gov/resources/medicare-physician-other-practitioners-by-provider-and-service-data-dictionary . Current schema and an A0429 public row for NPI 1003006180 were observed in the CMS API before implementation. Runtime read-only endpoint queries exact NPI without a state filter, credential match, or state roster precondition. Bounded pages, exact NPI membership, published organization rows only, HCPCS allowlist, row-level units, averages, reporting year, source links, explicit suppression and evidence status. The Financial Intelligence tab has an on-demand same-origin lookup. Missing or conflicting NPI identifiers are not guessed. Unverified recorded NPI may be queried but neither identity linkage nor operational relationship is established by the result. No automatic account mutation, claim-count or denial-rate inference, all-payer revenue extrapolation or mapping changes. Null/empty/unavailable results differ from zero. Source year is pinned; update deliberately for a new release. A separate live smoke tests the API using the observed public organization NPI. Regional roster work continues independently; optional HTML table end tags are now parsed correctly without changing the exact header/column allowlist. State verification is not a merge gate or prerequisite for legitimate federal data; end-user validation and provenance are retained. Replit remains untouched.
