# Phase 6.2K - bounded reviewed station competitive map

An opt-in private station map is now available on the GIS and Google territory screens alongside the existing reviewed account map. It checks at most five linked accounts in a selected parent department state. Replit validates each saved parent and obtains a complete current NERIS station response, refuses ambiguous/incomplete sources or over-limit accepted evidence, and returns minimal reviewed dated observation fields only. It never exports note contents or reviewer identities in the map response. Stations without a qualifying named manufacturer stay unknown. Duplicate native station identities across selected accounts are withheld, not counted twice. Family and 90/365/730-day filters apply only to accepted observations, not current installed fleet claims. A mixed parent means both kinds of observations occur across sampled stations. Location is source-reported, not field validated. Cross-state stations retain their own state; county is not inferred from headquarters. Unavailable accounts are reported separately. Samples are private, in-memory, expire after five minutes and are cleared on offline or close.

No production schema changes, no map mutation, no existing provider records altered, and no invented equipment. Nationwide county aggregation, replacement opportunities, EMS-only stations and full competitive market coverage remain outstanding. Replit deployment and previous additive table deployment must be confirmed before use. CI tests use only disposable local PostgreSQL and fixtures.
