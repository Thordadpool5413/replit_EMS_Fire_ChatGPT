# Phase 8.0O: Minnesota statewide address research
MnGeo published 2026-10-08 opt-in compilation (59 counties): https://www.arcgis.com/sharing/rest/content/items/39e1d5e08885476c82adcad9896681b6/info/metadata/metadata.xml?format=default&output=html . Live layer: https://enterprise.gisdata.mn.gov/aghost/rest/services/us_mn_state_mngeo/loc_addresses_open/FeatureServer/0 . Uses published field types, exact reconstructed street and postal city/ZIP, Census county reconciliation, native object IDs, dates and bounded WGS84 geometry. Literal lifecycle and placement codes are retained for review rather than interpreted as operating status. No accepted pins, automatic identity association, full statewide census, or Replit changes. Fixture tests are synthetic tests only. Wisconsin's 41 placement issues require the observed literal values and authoritative interpretation before changing acceptance criteria; published OEC guidance https://oec.wi.gov/wisconsin-ng9-1-1-gis-data-standard-best-practices/ describes multiple placement types but does not establish the rejected records' actual values.
