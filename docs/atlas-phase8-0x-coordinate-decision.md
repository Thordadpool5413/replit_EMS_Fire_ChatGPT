# Phase 8.0X: private coordinate acceptance and rollback

Private editor-only, revision-checked decision endpoint accepts retained coordinate evidence after exact native registry identity, source revision, current acknowledged confirmation, county, shared-point and independent placement-attestation checks. Original coordinates are server-selected from retained evidence, not request fields. Rollback appends a decision instead of deleting evidence. Generic agency writes cannot inject or remove server-owned decision history; public profiles omit it. Acceptance is an attributable user statement about an address point, not an independently established operational station or a public pin. All entries remain publication-ineligible. No map or national snapshot changes, no Replit deployment. Current release has 72 historical source records, 61 points. UI and deployed endpoint verification remain pending. No actual user decisions have been created.
