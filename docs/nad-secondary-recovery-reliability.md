## Archive-based correction

Run 45644898485 reproduced all three timeouts even with one address per request. The secondary workflow now directly uses the already successful pinned USDOT archive download and complete streaming scan, not the unresponsive ArcGIS API. It checks the exact SHA-256 observed in the earlier successful archived recovery, ZIP integrity, schema, minimum row count, existing mappings and additive release constraints. A complete zero-gain scan is a successful search with no changes; a download, digest, scan or validation error remains a failed action. This avoids treating a real outage as a successful match. The workflow targets FL and OH by default, and a manual run may specify other states. Historical failures remain visible.
