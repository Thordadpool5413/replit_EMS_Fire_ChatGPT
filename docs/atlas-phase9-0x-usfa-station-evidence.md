# Parallel fire station address acquisition

USFA's existing nationwide legacy station CSV is a separate federal source from NERIS, listing station or independent fire-company addresses voluntarily supplied by registered departments. Acquire it once rather than performing state-by-state lookups. Preserve literal FDID strings and use headquarters state + FDID for parent comparison against the pinned national snapshot. Cross-state station addresses, unmatched parent rows and duplicate source fields remain visible as distinct evidence. Source row fingerprints are not station identifiers. The file does not establish current operating status or complete station coverage. No inferred coordinates or state licensing prerequisite. All actual acquired counts are emitted from the live workflow, not fixture data. Original source checksum and national snapshot checksum retained. Replit untouched.
