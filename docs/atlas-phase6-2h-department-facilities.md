# Phase 6.2H — department and station grain

A separate read-only Replit API endpoint retrieves public fire facilities using an exact parent source identity. USFA uses department HQ state + FDID and now preserves the distinct station state; NERIS verifies the exact department ID against its state roster and queries its explicit Department_Station relationship, not a fuzzy name match. NERIS source-native station IDs and WGS84 geometry are retained separately; invalid points are withheld, duplicates are not accepted, and no coordinates are inferred for USFA. USFA source rows lack native station IDs; no fabricated ID is assigned. The UI loads on explicit expansion and shows source rows separately, never adds counts across overlapping registries, never writes provider records, and never substitutes a station for HQ. Source coordinates are not independently field verified. Directions use a reported physical street address only. End-user validation remains required. EMS-only station discovery and persistent station reviews remain future work. No national map pin changes, production database migration or new backend. Live upstream and Replit deployment still require verification. Source schema: research/sources/neris-05-station-layer-schema.md.
