# Phase 8.0N: Wisconsin address recovery diagnostics

The successful live acquisition run 45702568090 reported 309 source records: 46 review, 260 no match, 3 unsupported, and zero accepted candidates. Its artifact 15062683971 contained only aggregate counts, so the cause of each unresolved record was not established. The government layer schema had no coded domain for Placement or County. This revision adds per-source-key disposition, exact-address object IDs, bounded reason codes, eligible point count, and aggregate reason counts. Reason counts may overlap; candidate records are excluded from reason counts. The existing acceptance criteria remain unchanged. No rejected coordinates or source attributes are published, no provider dataset or Replit records are changed. Tests cover county, placement, subaddress and absent exact-match outcomes. Live rerun required before claiming recovery.
