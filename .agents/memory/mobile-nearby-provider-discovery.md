---
name: Mobile nearby provider discovery
description: A stated user need for quickly finding EMS and fire agencies around the mobile app user.
---

Mobile users need a fast way to find nearby EMS and fire departments.

**Why:** The user identified the lack of nearby discovery on phones as the largest obstacle to using the app.

**How to apply:** Keep a direct mobile entry point to location-assisted agency results, retain manual search when location is denied or unavailable, and explain that recorded-point distance is not drive time or service coverage.
